说明

这些数字是什么意思

  • 访问量（PV）：页面被打开的次数。同一会话里同一页只记一次，刷新不会重复计数。
  • 独立访客（UV）：按「当日 + 访客标识哈希」去重后的数量，不是精确人数，但能反映大致规模。
  • 今日 / 近 30 天 / 总计：今日和近 30 天读的是每日明细表，总计读的是累计表。

为什么博文和工具要分开排

  • 两者的访问规律完全不同：博文靠搜索和老链接慢慢积累，工具页可能因为被分享而短时间冲高。
  • 混在一起排，工具页会长期压住博文，反而看不出哪篇文章真正受欢迎。
  • 「其它页面」收纳的是首页、归档、分页等非内容页面，一般不用关注。

统计口径与限制

  • 计数在浏览器端发起，因此：禁用 JS、使用阅读模式、或直接抓取页面源码的访问不会被计入。
  • 不会记录 IP 原文：访客标识是「IP + 日期」的哈希，每日明细 90 天后自动清理。
  • 工具页里像 /assets/web/tools/gif.html 这样的独立页面也在统计范围内。
  • 被搜索引擎爬虫访问也会计入（无法可靠区分），所以数字会略高于真实读者数。
  • 本页数据来自仓库 cf/ 目录里的自建后端（Cloudflare Worker + D1），不依赖任何第三方统计服务。
