全部评论

每条评论下面都有「回复」，回复同样会出现在对应文章页面的评论区里。 刚发出去的一分钟内，可以在自己那条评论上点「撤回」。

说明

怎么用

  • 留言：在「写点什么」里写好内容，选一篇文章（或选「公共讨论区」聊与具体文章无关的事），点发表即可。 发出去之后，对应文章页面下面的评论区里也会同时出现。
  • 回复：点任意一条评论下的「回复」，内容会挂在那条评论下面，对方刷新页面就能看到。
  • 看自己的：点「我的评论」，只看这台设备上发过的，回来看看有没有人回复你。
  • 昵称与邮箱：填一次就记在这台设备上，下次不用重填；邮箱只用于取头像，不填也行。

发不出去的时候

  • 两次发布之间有 20 秒间隔（与文章页的评论区一致），防止刷屏。
  • 内容不能为空，也不要重复提交刚发过的同一段内容。
  • 若提示网络错误，先确认当前网络能不能访问评论服务（国内有时会被拦）。

关于显示

  • 按文章分组，点分组标题可收起 / 展开；也可以搜索昵称、评论内容或文章。
  • 评论按纯文本渲染，网址自动变成链接，`反引号` 里的内容显示成代码样式。
  • 带「站长」标记的是站点作者本人的回复。
给站长的备注（普通访客可以跳过）
  • 评论与访问计数都存在自建后端里（Cloudflare Worker + D1 数据库）， 不再依赖 LeanCloud —— 后者将于 2027 年 1 月 12 日停止服务。
  • 页面源码里不再有任何可写的密钥。写入必须经过后端校验（长度、频率、来源、机器人陷阱）， 所以外人无法像以前那样用公开的 appKey 直接改删评论。
  • 访客发出去一分钟后自己删不掉（服务端只给 60 秒撤回窗口），需要站长在 管理页处理。
  • 限流按 IP 哈希计数、访客去重也只用当日哈希，不存储任何 IP 原文；邮箱仅用于取头像， 公开读取接口不会返回它。更详细的运维说明见仓库里的 cf/README。
