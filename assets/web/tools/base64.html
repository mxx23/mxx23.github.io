使用说明

  • Base64 不是加密算法，只是把二进制数据用 64 个可打印字符表示出来，任何人都能还原，请不要用它保护密码等敏感信息。
  • 编码后体积约为原来的 4/3（约 133%），因此把大图片转成 Base64 内嵌进网页会显著增大页面体积。
  • URL 安全模式使用 - 与 _ 替换 + 与 /，适合放在 URL 参数或 JWT 中；解码时两种写法都能识别。
  • 本页所有计算都在你的浏览器中完成，文件不会被上传，也可以断网使用（把页面另存为本地文件即可）。
