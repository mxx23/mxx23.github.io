使用说明

  • 校验采用自行实现的严格 JSON 解析器（遵循 RFC 8259），出错时会给出行号、列号与具体原因，并附上出错位置的原始行。
  • 支持标准 JSON 之外的少量“类 JSON”写法提示：单引号字符串、注释、尾随逗号、NaN、十六进制数字等非标准语法都会被指出。
  • 大整数保护：树形视图按原文显示数字，超出 Number.MAX_SAFE_INTEGER 的整数会给出精度提示。
  • 严格模式下，同一个对象中重复出现的键名会被视为错误；非严格模式只在状态栏提示，并按“后者覆盖前者”的常规行为处理。
  • 全部解析在浏览器本地完成，输入的敏感数据不会发送到网络上。
