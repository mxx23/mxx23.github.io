使用说明

怎么用

  • 加帧：把图片拖进虚线框（可一次多张），也可以点「从网址添加」贴图片链接。 加进来的顺序就是播放顺序。
  • 调顺序：每张图下面有 ← → 可以左右移动；「倒序」把整条胶片反转； 「乒乓」会在末尾自动补上反向帧，做成来回播放的效果。
  • 调速度：每帧可以单独设置延迟（毫秒）。想统一改就改「默认帧延迟」， 再点「把下面的延迟应用到全部」。
  • 合成：点「④ 合成 GIF」，完成后上方会出现预览和「下载 GIF」按钮。

关于体积

  • GIF 的体积主要取决于尺寸、帧数和颜色数。把输出尺寸降到一半，面积就只剩四分之一，体积下降最明显。
  • 颜色数从 256 降到 64 通常能省 20%～40%，肉眼几乎看不出差别；降到 16 会明显失真，适合图标类。
  • 本工具会自动为所有帧生成一张共享调色板，因此画面颜色越集中、压缩率越高。

关于画质

  • GIF 最多只能有 256 种颜色，所以照片类图片必然有色彩损失，这是格式本身的限制，不是本工具的问题。
  • 缩放使用浏览器的高质量插值（多级降采样），比直接把大图硬缩到目标尺寸更清晰。
  • 各帧尺寸不一致时，会统一缩放到你指定的输出尺寸；留空则按第一帧的尺寸，其余帧等比适配。

隐私

  • 所有处理都在你的浏览器里完成，图片不会上传到任何服务器。断网也能用。
  • 页面本身是纯静态的，没有后端；合成速度取决于你电脑的性能。

已知限制

  • 不支持直接导入视频文件。要视频转 GIF，可以先用截图或视频工具导出图片序列再拖进来。
  • 不作逐帧独立的局部调色板优化（所有帧共用一张 256 色调色板）， 因此色彩跨度极大的素材（例如一段彩虹渐变视频）体积会比专业软件略大。
  • 单次建议不超过 200 帧或 2000×2000 像素，否则合成会明显变慢（受浏览器内存限制）。
  • 透明度是二值的：alpha < 128 的像素算全透明，其余算不透明，这是 GIF 格式的固有限制。
