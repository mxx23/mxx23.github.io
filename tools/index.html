关灯

　　这里收集了本站用纯 JavaScript 实现的一些在线小工具。它们全部在浏览器本地运行，不依赖任何后端服务：输入的文本、上传的图片和视频都不会离开你的电脑，断网也能继续使用（把页面另存为本地文件即可）。

　　这些工具都是纯前端实现的，不依赖任何后端。

　　另外还有一个需要联网的页面：导航栏里的 访问统计 —— 它要读写访问计数，
后端是本仓库 cf/ 目录里的 Cloudflare Worker + D1 数据库。

📊 访问统计（博客与工具排行）

日访问量、近 30 天访问量、总访问量与独立访客数；博文和在线工具分开排行，附每日趋势。需要联网读取后端数据。

🔢 Base64 在线编码解码

文本与 Base64 互转（完整支持中文 UTF-8）、URL 安全字符、MIME 换行；文件与图片转 Base64 / Data URI，Base64 还原为文件下载。

🧩 JSON 在线解析

JSON 合法性校验并精确定位错误行列与原因；格式化 / 压缩 / 键名排序 / 转义；可折叠的结构树、路径查询、键值搜索，以及节点数与嵌套深度统计。

🎬 在线视频压缩

在浏览器里真正重新编码视频：调整分辨率、码率、帧率，裁剪片段，导出 MP4 / WebM。压缩耗时约等于视频时长，视频不上传。

📽️ 图片合成视频（幻灯片视频）

把多张图片做成幻灯片视频：可设每张时长、横竖屏比例、分辨率与帧率，支持淡入淡出、横向滑动与镜头推拉特效，还能配背景音乐，输出 MP4（H.264）或 WebM。

🎞️ GIF 合成器（图片转动图）

把多张图片合成 GIF 动图：可拖入一批图片、逐帧调延迟、倒序与乒乓播放、指定输出尺寸与颜色数，透明背景也能保留。内置自写的 GIF89a 编码器，没有第三方依赖。

🖼️ 在线图片去背景（抠图）

自动识别纯色 / 渐变背景并转为透明，支持容差调节、边缘羽化、去杂边，以及橡皮擦与恢复笔手工修补，导出透明 PNG。

🔐 AES 在线加解密（AES-128 / AES-256）

用口令或原始密钥加密文本与文件，支持 AES-GCM（带完整性校验）与 AES-CBC；密文自带算法与参数，解密时自动识别，也可以切换成不含头部的「裸模式」与 OpenSSL 等程序互通。

🔍 文件 / 目录差异比较（在线 Diff）

比较两个文本文件（逐行对齐 + 行内高亮）或两个文件夹（递归比较、按状态着色），把差异按块或整份覆盖到另一侧；有写回权限时直接落到磁盘，否则打包成 ZIP 下载。

说明

  • 工具页面本身是独立的静态 HTML，放在 source/assets/web/tools/ 目录下，由 Hexo 原样复制到站点中，可以直接分享链接给别人使用。
  • 每个工具页面的底部都写了它的功能、使用技巧，以及实现原理与能力边界，遇到问题可以先看那里。
  • 文章列表里对应的“工具介绍”文章会自动跳转到工具页面，方便从博客里直接进入。
  • 访问统计页放在 source/assets/web/stats/，需要联网读取后端数据。
  • 访问计数的后端在仓库的 cf/ 目录里：一个 Cloudflare Worker + D1 数据库，记录每篇文章、每个工具页的访问量。
    首页的「热门文章」排行、文章页的阅读次数也都读它。
